📚 RAG 知识库问答系统

一个基于 RAG（检索增强生成） 的个人知识库问答项目，使用 Streamlit + 向量检索 + 大模型 构建，支持上传文档并基于内容进行智能问答。

🚀 项目特点
📄 支持上传文档（txt / pdf / csv / md）
🔍 自动文本解析与切片（chunking）
🧠 基于向量检索的语义匹配（RAG）
💬 Chat 对话式问答界面
🗂️ 文件管理（上传 / 删除 / 查看）
💾 文件元数据持久化存储
⚡ 基于 Streamlit 的可视化交互界面

⚙️ 技术栈
🐍 Python 3.10+
🎈 Streamlit
🤖 大模型 API（DashScope / OpenAI 兼容）
📦 Pandas / NumPy
📄 PyPDF / CSV 解析
🧠 向量数据库（Chroma / 内存向量存储）
🔤 文本切分（Text Splitter
